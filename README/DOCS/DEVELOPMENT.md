## Design rules

1. **Determinism is a feature.** All random draws happen on the calling thread. Evaluation is the only thing sent to Rayon, and results return in input order. A test compares a one thread pool with a four thread pool and requires identical output.
2. **No hidden state.** Bounds live in the problem, caches are per instance, and no global mutable state exists. This is why a benchmark can be built twice and compared.
3. **The traits stay small.** A problem supplies its dimension, bounds, objective count, constraint count and one evaluate function. Everything else has a default.
4. **Scores own their numbers.** `Score` stores objectives, constraints and the derived violation, so selection never recomputes a constraint.
5. **Numbers that matter are named.** Defaults are public constants such as `de::DEFAULT_BUDGET_PER_DIM` and `moead::DEFAULT_BUDGET`, and the documentation quotes them.
6. **A failed fit is not a panic.** Ridge returns `Option`, and the search treats `None` as a large error.
7. **No unsafe code.** There is none in the crate.

## Dependencies

Four crates, each doing one job: `rayon` for the evaluation batch, `clap` for the command line, `serde` and `serde_json` for JSON Lines input and the report output. The random generator, the linear algebra and the optimisers are in the crate.

`argmin` was considered for the solvers and is not used. It is a good framework, but it ships CMA-ES, particle swarm, simulated annealing and gradient methods, not SHADE, jDE or MOEA/D, so it would replace none of the algorithm code. It would add a solver type parameter and a second problem abstraction on top of a trait that is already six methods. The parallel evaluation here is also part of the reproducibility contract, which is easier to guarantee directly than through a generic backend.

## Adding a problem

Implement `Problem` and pass it to either engine. Constraints are optional and follow `g <= 0`.

```rust
use xcm_mmm::problem::{Bounds, Problem};

struct AckleyLike {
    bounds: Bounds,
}

impl Problem for AckleyLike {
    fn name(&self) -> &str {
        "ackley-like"
    }

    fn dim(&self) -> usize {
        self.bounds.dim()
    }

    fn bounds(&self) -> &Bounds {
        &self.bounds
    }

    fn evaluate(&self, x: &[f64], f: &mut [f64], _g: &mut [f64]) {
        f[0] = x.iter().map(|v| v * v).sum::<f64>().sqrt();
    }
}
```

The implementation must be `Sync` and pure. Purity is not enforced by the compiler, but a problem that returns different values for the same point breaks reproducibility and invalidates the memory of successful parameters.

To add a benchmark, extend `Kind` and the `CATALOGUE` table in `src/benchmarks.rs`, add the formula to the `evaluate` match, and add a known point test. The catalogue test builds every entry at its default dimension, so a missing arm fails immediately.

## Tests

```bash
cargo test
cargo test --lib                       # unit tests only
cargo test --test de_quality           # one integration suite
cargo test moead::tests                # one module

```

The suite has 282 tests and runs in a few seconds in debug. It covers:

- convergence on sphere, Rosenbrock, Rastrigin and Ackley for every adaptation and mutation
- reproducibility at one and four threads, and identical history
- a constrained problem whose optimum is known
- ZDT1, ZDT2 and ZDT3 fronts, checked for IGD, non-dominance and point count
- exact hypervolume identities in two and three dimensions, and Monte Carlo agreement
- simplex lattice counts and neighbourhood correctness
- the forecasting path, including that the selected subset overlaps the true informative features
- the detector fit from bank to artifact, and the segmentation path from panel to artifact, each with its refusals
- every CLI subcommand, including the JSON shape and the wrong engine refusal

Tests assert thresholds with headroom, so a change in the random stream does not make the suite flaky. If a threshold fails, check the algorithm before relaxing it.

## Performance notes

- Build with `--release` for measurements. Debug builds spend most of their time in bounds checks.
- Threads come from Rayon. `RAYON_NUM_THREADS=4 cargo run --release -- ...` fixes the pool size; the answer does not change, only the speed.
- The expensive part of a DE generation is the batch of trials, and the expensive part of a MOEA/D generation is the batch of children. Both are evaluated with `par_iter`, so a problem with a cheap evaluation will be dominated by the Rayon overhead. That is expected; the forecasting path is the target workload.
- A forecast evaluation fits one ridge model per fold. Reducing the fold count or the feature count is the effective way to speed up a search; the population size matters much less.

## Roadmap from the limits review

The cards name eight boundaries. This section turns each into a change, an order and a number that would say the change worked. The ordering rule is cheapest evidence first: a measurement that costs one fold and settles a question goes before a learner that costs an MCMC chain.

### Closed

**Embargo cannot be shorter than the label horizon.** A target that reaches `h` rows forward overlaps every row within `h`, so a training row at the edge of a fold saw the label of the row after it. `data::horizon_embargo` raises the gap, `forecast --horizon h` sets it, and a fold test asserts the gap equals the horizon. Until now the default of 1 leaked on any multi-row label.

**The search now prices itself (roadmap item 1).** `src/deflate.rs` records every distinct column set the forecast search scores, deduplicates the masks the engines revisit, and turns the winning score into `z`, the expected maximum of that many standard normals under the null, and a p-value. Three decisions are worth reading. Duplicates are one bet, not two, so the trial count counts distinct sets. Dependence between candidates is measured on the log fold profiles after the fold effect is removed, by cosine rather than correlation, because candidates that differ only by level are fully dependent and Pearson scores them as noise. The two corrections pull in opposite directions, so the gate quotes the larger of the two floors and says which is which. A synthetic 800 row panel with 12 features clears neither at 0.95: 1,179 distinct subsets, `z` 1.37, floor 3.30, budget 6 candidates, which is the seven-candidate rule of Bailey et al. (*Notices of the AMS* 61(5), 2014) showing up in this crate's own numbers.

**AUC intervals that hold where positives are scarce (item 4, interval half).** `uncertainty::delong_auc` computes the DeLong variance from the structural placements of every positive and negative and reports the bounds on the logit scale, so they cannot leave `(0, 1)`. On the shipped churn panel the DeLong reading is 0.867 `[0.858, 0.876]` with a standard error of 0.0046 against the bootstrap `[0.857, 0.876]`, and the card quotes the wider of the two.

**Every interval is now checked against a known truth (item 4b).** `uncertainty::bca` adds the bias and acceleration corrections, with the jackknife on the same placements DeLong uses, and `uncertainty::coverage` runs the simulation the roadmap demanded: 251 rows, 50 positives, a two normal world whose true area is 0.760 in closed form, nominal 95 percent, acceptance band 0.93 to 0.97. Bootstrap-percentile covers 0.938 at a mean width of 0.144, BCa 0.936 at 0.145 and DeLong 0.947 at 0.146, all inside the band at 2,000 trials.

The first version of this paragraph said the opposite, and the correction is the useful part. At 200 trials the same simulation put DeLong at 0.925, below the 0.930 floor, and the claim went into the card as a failure of the analytic interval. A share measured from 200 trials has a standard error near 0.015, which is wider than the gap; rerunning at 2,000 moved DeLong to 0.947. `uncertainty::wilson` now reports the interval on each measured share, `MethodCoverage::missed` refuses to call a miss resolved while that interval still reaches the band, and a test pins the arithmetic: separating a half-point gap at this level takes about eleven thousand trials. The lesson generalises past this panel. A coverage simulation is itself an estimate, and a card that prints one without its Monte Carlo error is quoting noise to two decimal places.

**The selection now has a distribution, not one path (item 2).** `forecast --cpcv` cuts the panel into contiguous groups, withholds `k` of them at a time, purges a gap on each side of every withheld run, and reads the distribution of paths and the probability of backtest overfitting. On the synthetic 800 row panel at `N = 6, k = 2` and a purge of 1, that is 15 splits and 5 paths: path spread 0.0027 in MSE, PBO 0.667, and a verdict that says selection lands in the better half on a third of the splits, which is a coin. The gate from item 1 and this audit agree, and they were built from different statistics.

**Class conditional conformal (item 5).** `uncertainty::mondrian` fits one threshold per label and refuses an `alpha` below `1 / n_c` for a class instead of printing a quantile it cannot estimate. At 90 percent on the churn panel the churn class covers 0.896 at a mean set of 1.90 and the stayed class 0.907 at 0.92, against a pooled 0.917 at 1.24. The pooled number was hiding that gap.

**The intervention question now has an estimate and a limit (items 7 to 10).** `causal` keeps the cross-fitted nuisances and reads them four ways: a doubly robust pseudo-outcome with an influence function interval, `dr_ate` 0.204 `[0.152, 0.257]` on a planted panel; an overlap weighted estimate that targets the population a decision can act on; a Crump trimmed estimate with its bound and retained row count; and an E-value of 2.44 with a 2.15 near-null bound, which states what unmeasured confounding would have to be, not that none exists. The policy value curve replaces Qini as the decision reading: the top decile is worth 0.338 against 0.204 for treating everyone. Qini stays as a descriptive ranking number, and it had a sign error until this round: the random baseline used the marginal treated-minus-control difference instead of the within-decile total, which reports a negative Qini for a correctly ranked model whenever the treated share varies by decile. A test now pins the sign.

### Phase 1, make the selection defensible (no new models)

Closed. Item 1 and item 3 are the deflated gate, and item 2 is `forecast --cpcv` above: the gate prices how many bets were placed and the audit reads what happens when the split changes, so the selection is now criticised by two statistics that were built separately and agree on this panel. What is still not done, deliberately: the gate does not veto a run, because a veto at this trial count would refuse every search the crate can afford. It reports a candidate budget and a verdict, and the reader decides.

### Phase 2, uncertainty the sample size can carry

Closed, with one measured limitation.

4. The logit DeLong interval and item 4b, BCa plus the coverage simulation, both landed. The simulation's finding is that all three intervals hold at 50 positives once the trials are enough to see the difference, and that the first run was not: 200 trials reported DeLong at 0.925, 2,000 reported 0.947. The card quotes the measured coverage with its Monte Carlo interval rather than choosing an interval on a claim the simulation could not support.

5. Class conditional conformal with a refusal below `1 / n_c` landed as `uncertainty::mondrian`.

6. **Beta calibration landed as the default under a thousand rows.** `uncertainty::calibrate` fits `sigmoid(a ln p - b ln(1 - p) + c)`, three parameters, which handles over-confidence where isotonic would collapse in sample (Kull, Silva Filho and Flach, AISTATS 2017; Niculescu-Mizil and Caruana, ICML 2005, is the reason isotonic is not the default below about a thousand rows). On the churn panel the map is `a` 1.716, `b` -2.093, `c` +0.333, and the in-sample error falls to 0.006 from 0.075. The card says in sample, in bold terms, because that number is flattered by fitting and calibrating on the same rows. The delivered part of the item is the interval: ECE 0.075 `[0.069, 0.084]` and Brier with its own interval, both from resampling rows so the bins move with the sample. The honest held-out calibration comparison is open, and it needs a split the fit does not see, which is one extra fold and not a new method.

### Phase 3, the question the crate could not answer

Items 7, 8, 9, 9b and 10 landed: the doubly robust estimate, the E-value, the two overlap estimands, the policy value curve, and the window contract. What is open:

**Time zero is now a checked contract, not an assumption (item 9b).** `src/churn/contract.rs` asks the four questions a survival panel has to answer before a lift means anything: where time zero sits, whether month 0 can appear, how many rows are censored rather than counted as survivors, and how many months carry fewer than 30 rows at risk. On the shipped panel time zero is the join, month 1 is the first month at risk, 356 of 7,043 rows are censored at month 72, and no month falls under the at-risk floor. `churn check` recomputes the contract from the panel and the series independently and refuses when they disagree on the event count, so a panel edit that changes the window cannot pass silently. This closes what the roadmap called a data contract, with the limit stated in the card: the contract is written against month numbers, so a panel whose time zero is a campaign start has to shift and truncate before the check applies, and the repository has no such panel.

7b. **A causal forest is refused, deliberately.** At a few hundred rows the honest forest interval is wider than the decision it would support, so the tree ensemble stays a nuisance model behind the doubly robust score rather than a heterogeneity estimator.

### Phase 4, segmentation

11. **Bound every component's conditioning, not only its diagonal. Landed, at a cap the measurement chose, which is not the cap this item asked for.** The variance floor raises the diagonal, so an oblique component with a near-singular covariance still survives; the ratio of a component's longest axis to its shortest is now capped (`mixture::CONDITION_MAX`), with a Jacobi eigen-decomposition in `linalg` behind `condition_number` and `conditioning`. Two decisions came out of the measurement rather than the design. First, the bound is applied by `ship` to the model that ships and not inside the maximisation loop: clipping every intermediate covariance steers the search away from the shape the data supports, and the full covariance family reads 0.543 nats per entity held out with the shipped-model bound against -2.022 with the in-loop one at a cap of ten thousand, with identical placement agreement in both. Second, the cap is a trillion and not ten thousand. An eight column covariance from about two hundred rows carries an eigenvalue error of 0.08 against a longest axis of 1.4, so no ratio below about twenty can be separated from sampling error at all, and the sweep shows what a statistical-sounding cap costs: ten thousand and a million both hand the choice to the diagonal family at k = 5 with the full covariance fit at -1.668, a billion reads it at -0.095, a trillion at 0.543, unbounded at 0.609. A trillion is the edge of what a double-precision factorisation can invert, so it refuses a direction flat to twelve digits and nothing else. Shipped: full covariance at k = 4, held out 0.543 with a spread of 2.344 across folds, placement agreement 0.813, worst component 6,089, no component lifted, silhouette 0.222 against a 0.168 shuffled control. The honest summary is that a ratio cap cannot separate real near-collinearity from memorisation on this panel, so the card says that and prints the sweep instead of claiming a statistical bound it does not have.
12. **A two-part model for the zero mass. Closed as a gate with a measured acceptance, and the item's premise was wrong on this panel.** The item said clipping at 3 sd smears the spike. It does not: the clip never fires on either share, because a share with a boundary mass of `p` has its edge at `sqrt((1-p)/p)` in z, which is 1.22 for `repeat` and 0.68 for `concentrate`. The clip fires on ad volume, cadence, burstiness, spend, copy words and terms. What the pile costs is a group: a Gaussian can only imitate an atom with a component of almost no width, and then it reports a density where the data are a probability. `src/segment/gate.rs` fits, inside each chosen group, the chance a member sits on the edge and a normal for the members inside it whose mean moves with the other readings, which is the classical two-part model (Duan et al., *JETA* 22, 1983; Aitchison, *JRSS-B* 44, 1986, is the alternative the item offered and this panel did not need). The clip is nonetheless exempted on a gated column, because a share whose edge sits beyond the bound would have its edge folded into the interior and the atom would have no meaning.

The acceptance was rewritten because the one it asked for cannot be read. A likelihood with an atom and one without are densities against different measures: on an edge row the gate reports a probability and the Gaussian reports a density, and at this panel's spacing density times spacing exceeds one, which is a model credited with probability it cannot represent. Both sides are therefore scored as the probability of the observed value on the lattice the share lives on, the multiples of `1 / ads`, with the cell integrated rather than approximated, paired by fold. Shipped: `repeat` -0.891 against -1.000 for the Gaussian conditional law, Brier 0.098 against 0.116; `concentrate` -0.916 against -1.055, Brier 0.107 against 0.129. That is 0.248 nats per entity across the two shares, and the edge is called right on 84.1 and 81.2 percent of held-out rows against 60.1 and 64.1 percent for the panel rate. The groups read as shares now: `repeat` at 0 covers 100, 27.7, 0 and 100 percent of the four groups, with the inside mean printed beside it, and no clipped z is used to describe either reading.

Two things are deliberately not done. The gate is fitted to the partition rather than inside the expectation maximisation loop, because the mixed measure makes a likelihood comparison across the two families invalid and the partition is chosen on likelihood. A prototype that put the gate in the loop confirmed the second reason: its six column marginal read -1.62 nats per entity on held-out rows against -0.98 for the marginal of the eight column fit, so the gated columns are carrying group separation the smaller Gaussian loses. That is a reason to keep the dependence and model only the atom, which is the pattern mixture of Ghahramani and Jordan (*Technical Report CMU-CS-93-116*, 1993) and is the next step, not this one.
13. **Concomitant gating instead of exclusion.** Put recency and the other descriptive columns in the mixing weights, `logit(pi_k(x))`, and leave the densities on behaviour only (Dayton and Macready, *JASA* 83, 1988; mixture-of-experts, Jacobs et al., *Neural Computation* 3, 1991). That is how recency re-enters without measuring archive coverage inside the likelihood. Acceptance: the gating model adds held-out likelihood while the component means move less than a tenth of a standard deviation, and both numbers are printed.
14. **ICL beside BIC, and stability as a per-cluster flag. Landed, and the two halves gave opposite results: the per-cluster reading found a defect the aggregate had hidden, and ICL did not change a single choice.** ICL targets the partition and BIC targets the density (Biernacki, Celeux and Govaert, 2000; Baudry et al., *JCGS* 19(2), 2010), so `Mixture::icl` prints `BIC - 2 * sum log p` on every candidate and `segment info` shows the column beside BIC. On this grid the lowest ICL is the same near-saturated candidate as the lowest BIC, full covariance at k = 5, and the term that is meant to separate them is 0.3 nats across 251 entities, 0.001 per entity. The reason is measurable and it is the finding: a free covariance buys sharp posteriors, the chosen fit gives its own rows a mean winning posterior of 0.9994, so the ambiguity charge has almost nothing to charge. A criterion that is BIC plus a term that vanishes is BIC, and the card says that instead of implying the in-sample problem was repaired.
    The per-cluster Jaccard (Hennig, *CSDA* 52(1), 2007) did find something. Two of the four groups sit below the 0.6 floor: the 18 entity group at 0.266 mean (worst 0.079) and the 65 entity group at 0.589 (worst 0.352), against 0.626 and 0.893 for the other two, a mean of 0.593 across the partition. The aggregate resampling agreement of 0.712 passed, which is exactly the masking the item predicted: an adjusted Rand index weighs every pair of entities, so the large group that returns exactly pays for the small group that does not. Both readings ship: the card names each group with its size, share, mean and worst Jaccard, the limits section says a flagged group is a region rather than a membership, `segment fit` prints how many hold, and the manifest carries the same line into `segment check`. It is not a gate that refuses the fit, and that is a decision with a number behind it: excluding the small group by raising the share floor to ten percent moves the choice to full covariance at k = 3, held out at -2.653 against 0.543, so the likelihood prefers a partition with two fragile groups to a robust one that predicts badly, and refusing would be trading a measured strength for an unmeasured one.
15. **Quote the paired delta, never the absolute mean.** With five folds the standard error of 0.543 nats per entity is about 1.05, so no difference under a nat is resolvable. The comparison table is honest because it is paired; the headline sentence is not, and should carry the spread.

### Phase 5, small banks, cheapest first

16. **Audit the labels before buying more.** Confident learning estimates the joint distribution of noisy and true labels from out-of-fold predictions and ranks likely errors (Northcutt, Jiang and Chuang, *JAIR* 70, 2021). If 5 to 10 percent of the bank is mislabelled, that is the accuracy ceiling and a three-point gain sits inside it. Acceptance: the detectors, churn and emotion cards print estimated label noise and a ceiling.
17. **A learning curve that can see a ceiling.** Six or more sizes, each with its own train and test split, before any extrapolation (Viering and Loog, arXiv:2103.10948, 2023; Cortes et al., NeurIPS 1993). A flat four-point curve is evidence that the design is blind, not that the asymptote has arrived. Acceptance: `support` prints the fitted asymptote and rate with their intervals, or refuses when there are fewer than six points.
18. **A detectable delta on every card.** Hanley and McNeil's standard error is 0.025 at 251 balanced rows and 0.036 at 20 percent positives (Hanley and McNeil, *Radiology* 143, 1982), so a claimed 0.03 gain is about one standard error. Pre-register the minimum worthwhile delta and print the smallest gain the sample can resolve at 80 percent power.
19. **One transfer move.** A frozen subword embedding file with a hashed linear head is pure Rust and covers out-of-vocabulary words (Bojanowski et al., *TACL* 5, 2017; Weinberger et al., 2009). SetFit's few-shot result is the prior worth testing (Tunstall et al., 2022). Refuse self-training on twenty transcripts: the teacher is the weak link and confirmation bias is the known failure (Oliver et al., NeurIPS 2018).
20. **The encoder stays a fixture.** Do not claim it as a text model. The tabular question is already answered on the churn panel, trees 0.898 against logistic 0.867, which is the direction Grinsztajn et al. report (*NeurIPS* 2022).

### Phase 6, monitoring that is honest about labels

21. **A drift gate calibrated to the sample.** PSI is symmetrised KL on bins, so its 0.1 and 0.25 bands are sample-size dependent: the 95th percentile is 0.059 at a thousand rows per side and 0.338 at a hundred (Yurdakul and Naranjo, *Journal of Risk Model Validation*, 2020; Siddiqi, 2006, is the folklore source). Gate on a size-aware PSI threshold plus Cramer-von Mises with Benjamini-Hochberg across features, and add a joint MMD when the whole vector matters (Gretton et al., *JMLR* 13, 2012). Acceptance: a stationary backfill fires on under five percent of splits at a thousand rows per side.
22. **A matured-cohort table.** AUC, calibration, n, coverage and a paired DeLong against a frozen reference, all labelled with cohort age. Never compare a young cohort to a mature one; an unconverted case inside the window is censored, not negative (Chapelle, KDD 2014).
23. **An audit trail, not a pointer.** A registry version carries artifact digest, data digest and range, seed, metrics with n and maturity, reference distributions, parent and rollback pointer. That is the model-card and SR 11-7 minimum, and it is what makes a rollback defensible rather than a copy.
24. **Refuse a per-event error detector.** At 2 percent churn on 200 weekly labels there are four errors a week; no sequential rule separates drift from noise at that rate. ADWIN has a calibrated bound (Bifet and Gavalda, SDM 2007) and is the only one worth adding later, with `delta` tuned on a stationary stream rather than defaulted.

### What this roadmap does not close

- Unmeasured confounding stays unmeasured. The E-value quantifies how strong it would have to be; it does not remove it.
- Recency stays out of the densities. Moving it into the gating model changes what a segment means, and that change has to be read, not just shipped.
- Twenty transcripts stay twenty transcripts. No estimator turns them into a general claim; the only honest moves are transfer and more labels.
- The segment family choice remains one panel's answer. A second panel is the test, and there is not one in the repository.

### What the last two rounds bought, and what they point at

Twelve items closed since the review: the horizon embargo, the deflated selection gate, the CPCV audit, the logit DeLong interval, BCa with the coverage simulation, class conditional conformal, beta calibration with intervaled errors, the doubly robust and E-value causal reading, the window contract, the conditioning bound, the zero-mass gate, and ICL with the per-cluster Jaccard. The next three are the ones the new numbers point at.

1. **Quote the spread beside the headline (item 15), then the pattern mixture that puts the gate inside the loop.** The per-group reading just showed that an aggregate can pass while a component of it fails, and the same is true of the headline sentence: `choice` says 0.543 nats per entity and the fold spread behind it is 2.344, so the number a reader remembers is smaller than its own standard error of about 1.05. The fix is text, not estimation, and it is the cheapest honest improvement left on the board. The pattern mixture follows as the segmentation step that would let the gate move a boundary: keep the eight column Gaussian and marginalise a row's edge coordinates by pattern, imputing them at the conditional mean and adding the conditional covariance in the maximisation step, which costs one extra parameter per group per gate and keeps the separation the smaller Gaussian loses.
2. **Audit the labels before buying more data (item 16), and print the detectable delta (item 18).** The coverage simulation changed this ordering. It showed that at 50 positives an analytic interval can miss by two points while looking respectable, which means the small banks need a noise ceiling and a minimum resolvable difference on the card before anything else is fitted to them.
3. **A size-aware drift gate (item 21) with the matured-cohort table (item 22).** Monitoring is the one phase where the shipped code can produce an alarm that is simply wrong: PSI's published bands move by a factor of six between a hundred and a thousand rows per side, and the crate prints them without saying so.

Four defects surfaced while landing these rounds, and every one was found by writing the same number down twice and comparing. The gate's first dependence correction called an entire synthetic search one bet, because Pearson on near-parallel fold profiles divides by rounding error. Qini had the wrong random baseline and reported a negative coefficient for a correctly ranked model. The calibration note formatted the fitted error from full precision while the table beside it formatted a rounded value, so one number printed as 0.006 and 0.007 in the same section; `num::round4` is now the single definition and `check_docs.py` also fails a Rust string continuation that glues two words together, which is how the window paragraph shipped as `eventcount` and `month72`. And the coverage simulation reported a DeLong failure that was its own sampling noise, which is the defect that matters most because the tool was built to catch exactly that in other people's claims.

The shape is the same in all four: a number was printed without the precision it was measured to. That is the argument for the contract these cards now follow. A printed number is a testable claim, and the test is that the quantity appears the same way everywhere, carries its interval, and is not asked to settle a difference smaller than its own error.

Two more surfaced in the last round. Five modules carried their own `commas`, so "1,355,000" and "1355000" could have appeared in one card; the single definition now lives in `num` with `round4`. And the conditioning bound's first cap was a round number chosen before the sweep existed, which would have shipped a different segmentation for no measured reason.
